# Icons and Tuck

The glass icons and Tuck poses are the files from the File Companion design system. They are used as supplied.

- `assets/icons/`: `folder`, `course`, `application`, `project`, `sensitive`, `unplaced`, `sort`, and `move-real-files`.
- `assets/mascot/`: `tuck-idle`, `tuck-carry`, `tuck-rest`.

`move-real-files` is only for a control that moves or renames files on disk. Tuck is not recolored. One pose is shown per screen, on an ember ground.
