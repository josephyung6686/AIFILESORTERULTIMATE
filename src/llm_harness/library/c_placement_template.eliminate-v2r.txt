HOW TO DECIDE

Eliminate first. Then choose among what is left. Then check that what is left is one thing.

First, strike every candidate the file contradicts. If the file states a term, an institution, a project or a course and a candidate expects a different one, strike it, whatever else fits. A conflict flag points at such a disagreement; read the text and confirm it.

Second, strike every candidate whose only support is a resemblance. A shared word that appears in many folders, such as a university's name, an email domain or a person's name, supports nothing on its own. A number that resembles a course code, a year or a room number is not one until the text around it says it is. A word that happens to contain a shorter word is not that shorter word. A file that resembles the kind of thing a folder holds, without stating anything that folder expects, does not belong in it yet. A group the file was merely retrieved as a candidate for is a resemblance; a group the person accepted it into is support.

Third, among the candidates left, take the deepest one every level of which is supported. Each candidate's description is a chain of levels, and each level expects a value. A level is "direct" when the file's released text states the value, "context" when only an accepted group the file belongs to carries it, and unfilled when neither does. A candidate with an unfilled level is struck; if a shallower candidate on the same chain has all its levels supported, that shallower one stands. A candidate described as a scoped fallback under a parent stands when the parent's levels are supported and no child's deeper level is.

Two spellings can be one thing. A file may spell a course, a project or an institution differently from the way the person labelled the folder. Whether they are the same thing is yours to judge from the evidence, and if you judge that they are, cite the file's spelling and say so in "why_it_supports". If you cannot tell, they are not the same thing, and the candidate is struck.

Fourth, count what is left. One candidate standing is your destination. A candidate described as a shared branch, meant for material that serves more than one course, project or application, is supported by the accepted groups the file belongs to: when the file belongs to two groups and one candidate on the list serves both, that candidate stands alone and is the destination, with each of its levels marked "context". Two or more standing, none of which is such a shared branch, is not a decision: the answer is "none", and the product asks the person. None standing is "none".

WHEN THE ANSWER IS "none"

When you answer "none", say in one sentence what was missing or what was left standing.
