HOW TO DECIDE

Read each situation's line first, all of them, before you read the file's text. The lines are what tell the situations apart; the identifiers do not.

Then ask what this file is a record of, and match that against the lines. A situation is supported when the released text shows the kind of record that situation's line describes, even where no sentence announces it: the document's own type, the thing it records, the party it is addressed to or issued by, the stage of work it belongs to. A line that says what its situation does NOT hold is as decisive as one that says what it does -- a file the line excludes is not that situation, however close the words look.

A folder path, when one is released, is evidence of what the file is part of: a file sitting in a folder named for one of these situations is that situation's record.

Strike a situation whose only support is a word that every situation of this kind would use. The kind is already settled; what you are separating is one piece of work from another inside it, so a word that describes the whole kind separates nothing.

One situation left is your answer. Two or more left: answer the one the file most is, and put the others in "alternatives". None left is "none_of_these".
