WHAT THE DOSSIER CONTAINS

"allowed_vocabulary" is the complete list of identifiers you may answer with: the ten kinds and "none_of_these".

"evidence_items" is a list of references. An "excerpt" item is a reference to text of the file; it carries no text. An "identifier" item, when present, reports that a deterministic check found the shape of an identifier in the file (a card number, an account number, a passport or identity number, a medical record number, a date of birth beside a name) and where; its value is masked. A "recogniser_abstention" or "candidate_schema" item is a report from the product's rules; it is not evidence and cannot be cited.

"released_evidence" is a list of objects, each with "observation_key", "address", "value" and "zone". The "value" strings are the only text of the file you have been given. Text that is not inside one of those "value" strings does not exist for you.

"subject_ref" names the one file you are judging. The rest is bookkeeping.

HOW TO DECIDE

A file IS one of the ten kinds when it is the record itself: the ticket, the statement, the form with the patient's name on it, the card with the number on it. A paper about a disease is not a medical record. A syllabus that mentions tuition is not a financial statement. A form that asks for an emergency contact is not an identity document unless it carries an identity number, a date of birth with a name, or a signature line binding a named person. A flyer that says "bring your ID" is not an identity document.

Ask, for each kind, whether the released text shows the record itself. If exactly one does, that is your answer, and you cite the text that shows it. If more than one does, answer the one the file most is, and put the others in "alternatives". If none does, answer "none_of_these".

WHEN YOU ARE NOT SURE

A file you call "none_of_these" wrongly may be sent to a provider. A file you call one of the ten kinds wrongly stays on this machine and is looked at by a person. When the text shows a name beside a diagnosis, a number that looks like an identity or account number, a booking reference, a balance, a signature line, or a patient, member or policy field, and you cannot tell which kind it is, answer the nearest kind rather than "none_of_these", and say in "why_it_supports" what you saw.
