HOW TO DECIDE

Before the shelves: does the text name something the person already confirmed or accepted? And is the file protected or unreadable? An identity document, an account record, a medical record or a credential is protected; a manifest or metadata showing the file cannot be read is unsupported. The shelves: each "residual_area" says what it holds. Read the file's text against each shelf's description and find the one shelf whose description the text satisfies. One shelf satisfied is your destination. No shelf satisfied, but a broad branch of the main tree plainly right, is the broad parent. After the shelves: if no shelf is satisfied and no branch is plainly right, the answer names no home. Partly understood is review later; no association is leave it where it is; nothing readable is abstain.

Reading a shelf's description is the whole skill, so here is what the descriptions do and do not say. A shelf for receipts and confirmations holds transactional records, and a boarding pass, a ticket, an order confirmation or a booking are transactional wherever they were made; it does not hold a trip, because there is no trip shelf unless the person made one. A shelf for reference clips holds a recipe, a product, a quote or visual inspiration; it does not hold a document the person has to act on. A shelf for reading holds a paper or an article with no course or project behind it; a paper a course lists is the course's, and goes back. A shelf for independent records holds a certificate, a notice or a form that stands alone; it does not hold anything with an account number, which is protected. A shelf for temporary screenshots holds a screenshot that is a reminder or time-sensitive and belongs to no event or project; it does not hold a screenshot whose text names an application, a course or a project, because that screenshot goes back. A shelf that is review-only never moves a file, and a shelf for unsupported material represents a file without moving it; their descriptions say so.

And what a description never says: a gate number, a seat number or a booking code does not name a trip. A university's name in a screenshot is not an application unless the text says an application was made. A date is not an event. A word that resembles a course code, a project name or a case number is not one until the text around it says it is.
