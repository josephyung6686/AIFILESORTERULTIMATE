HOW TO DECIDE

Read each situation's line first, all of them, before you read the file's text. The lines are what tell the situations apart; the identifiers do not.

Then ask what piece of work this file belongs to, and match that against the lines. A situation's files are everything a person keeps from being in it: what they were given in it, what they made in it, what was issued about them in it, and what they sent from it. A reading, a handout, a worksheet, a textbook page, a practice paper, a draft, a note: each is that situation's file when the person kept it as part of that piece of work, and the line's list of examples is a list, not a fence. "Record" in a line means the file belongs to that piece of work; it does not mean an official document, and a file is not struck because no institution issued it.

Do not decline a file because it is a published text, a table of figures or a picture rather than a document about the person. A published article, a passage, a chapter or a textbook page kept in a piece of work is that work's reading; a table of figures kept is that work's data, whoever published it and whether or not a project is named beside it. Ask which situation on the list is the one that keeps such things, and answer it; the file's own person kept it there, and that is the whole of what "record" asks.

A situation is supported when the released text shows the piece of work that situation's line describes, even where no sentence announces it: the document's own type, the thing it is about, the party it is addressed to or issued by, the stage of work it belongs to. A line that says what its situation does NOT hold is as decisive as one that says what it does -- a file the line excludes is not that situation, however close the words look.

Whose side the person is on decides between two situations that share one piece of work. Material a teacher handed to the person -- an assignment brief, a rubric, a study guide, a worksheet, a schedule, an evaluation form -- is the person's own situation as the one taught, not the teacher's situation, and not the institution's file about them: a situation whose line is the instructor's side, or the institution's records about a child, holds only files the person made as the instructor or received as the parent of the child the records are about. The same holds for every kind: a file the person received in a piece of work is that piece of work's file, on the person's side of it.

A folder path, when one is released, is evidence of what the file is part of: a file sitting in a folder named for one of these situations is that situation's record.

Strike a situation whose only support is a word that every situation of this kind would use. The kind is already settled; what you are separating is one piece of work from another inside it, so a word that describes the whole kind separates nothing. And do not let a line's purpose-word capture a document that another line names outright: a document one line names by its own kind -- a resume, a cover letter, a transcript, a syllabus -- is that line's situation, not the situation of a line that describes the purpose such a document might also serve.

When two situations both fit and one is the ordinary piece of work of this kind and the other is a special case of it -- a different provider, a different age of the person, a different institution, a different stage of life -- answer the ordinary one and put the special case in "alternatives". The special case is the answer only when the released text carries its distinguishing mark as a fact about the person's situation -- a registration for a named sitting, an application addressed to a named programme, a parent keeping records about a child -- and never because the document's subject matter resembles it: a practice paper for an examination inside a course is the course's file; a statement written for a programme the person is studying in is that study's file; a table of figures is data whoever published it. Read this rule before "none_of_these" too: a file that fits the ordinary piece of work is never a decline.

The person whose file this is, is the one who kept it: the student, the applicant, the researcher, the job-seeker. Assume that reading unless the released text shows the other side -- a parent keeping an institution's records about a child, an instructor's roster or answer key, an employer's file on an applicant. A worksheet, a schedule, an evaluation form or a study guide in the person's own files is theirs as the one taught, whatever school issued it.

One situation left is your answer. Two or more left: answer the one the file most is, and put the others in "alternatives". None left is "none_of_these".

WHEN THE ANSWER IS "none_of_these"

Never. The kind of this file is settled and the list was written to cover every file of the kind, so this file IS one of the situations on it. A file whose released text you can describe in a sentence is placed under the line that fits the sentence best, with the others in "alternatives". A file whose released values carry nothing to read -- camera metadata alone, an archive's entry names alone, a path and an extension alone -- is placed under the situation of its kind that keeps such files, cited to the metadata item by "metadata_field_name", with "why_it_supports" saying that the metadata is all there was. The person corrects a wrong placement in one edit; a question sent back to them is the answer you were asked for. "none_of_these" stays on the list only so that a malformed answer has a shape; an answer that uses it is counted as a failure to judge, never as a judgement.
