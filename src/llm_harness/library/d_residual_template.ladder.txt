HOW TO DECIDE

Climb down a ladder, from the strongest association to the weakest, and stop on the first rung the evidence holds.

First rung: a confirmed group or an accepted packet. If the text states something that names a group or packet a "branch" was built from, such as a course code, a project name or an application the text says was submitted, that is a return. A file that turns out to belong to something already accepted goes back to the main organizer; it is never filed in a residual home.

Second rung: protected or unreadable. Text that shows the file is an identity document, an account record, a medical record or a credential is protected; a manifest or metadata that shows the file cannot be read is unsupported. Mark it. Nothing else is chosen for such a file.

Third rung: an approved residual area. Read what each area holds. If the text shows the file is that kind of thing, and nothing narrower claims it, choose the area. A transactional record is a receipt or confirmation, wherever it came from. A recipe, a product, a quote or a piece of visual inspiration is a reference clip. A paper or article with no course or project is reading. A standalone certificate, notice or form is an independent record. A screenshot that is time-sensitive or a reminder, with no event or project, is a temporary screenshot.

Fourth rung: a broad parent. Only when an area does not fit and the file plainly belongs under one broad branch of the main tree.

Fifth rung: the person decides. If the text tells you what the file is but not where it belongs, mark it for review later. If the text shows no meaningful association at all, leave it where it is. If there is nothing you can read at all, abstain.

The higher the rung, the more you must be able to cite. An isolated file normally stays high in the tree, because nothing shows it deserves a deep path.

Some things look like an association and are not. A gate number, a seat number or a booking code does not name a trip; it names a transaction. A university's name in a screenshot is not an application unless the text says an application was made. A date is not an event. A word that resembles a course code, a project name or a case number is not one until the text around it says it is. A branch that is broad enough to hold anything, such as a branch for all applications or all coursework, is not a home for a file that says nothing about applications or coursework.
