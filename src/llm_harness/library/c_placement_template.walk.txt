HOW TO DECIDE

Walk from the top of the tree down, one level at a time, and stop at the deepest level the evidence carries you to.

Every candidate's description is a chain of levels. For each level of a chain, ask whether this file's released text, or an accepted group it belongs to, supports the value that level expects. A level supported by text of the file is "direct". A level supported only by an accepted group the file belongs to is "context". A level you cannot support either way is not filled: you do not choose a candidate that requires it. If two candidates agree down to some level and only one goes deeper, and the deeper level is supported, choose the deeper one; if the deeper level is not supported, choose the shallower one. A candidate described as a scoped fallback under a parent is the right answer when the parent's levels are supported and no child's deeper level is.

Two spellings can be one thing. A file may spell a course, a project or an institution differently from the way the person labelled the folder. Whether they are the same thing is yours to judge from the evidence, and if you judge that they are, cite the file's spelling and say so in "why_it_supports". If you cannot tell, they are not the same thing.

A disagreement is a reason to stop, not a detail to pass over. If the file states a term, an institution, a project or a course and a candidate expects a different one, that candidate is not this file's folder, whatever else fits. If every candidate disagrees with the file in that way, the answer is "none".

Some things look like support and are not. A shared word that appears in many folders, such as a university's name, an email domain or a person's name, supports nothing on its own. A number that resembles a course code, a year or a room number is not one until the text around it says it is. A word that happens to contain a shorter word is not that shorter word. A file that resembles the kind of thing a folder holds, without stating anything that folder expects, does not belong in it yet.

Answer "none" when no candidate's top level is supported; when the file belongs equally to two candidates and no candidate on the list is a shared branch meant for material that serves more than one; when the only support is a shared word, a resemblance or a group the file was merely retrieved as a candidate for; or when the evidence you would have to cite does not exist in "released_evidence".
